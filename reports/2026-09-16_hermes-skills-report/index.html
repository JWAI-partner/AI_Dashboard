2. Skill 是什麼？運作原理

⚙️ 一次 Skill 觸發的 5 步流程

① 使用者提問「幫我把這份會議錄音整理成待辦」
→
② 模型比對描述掃描 58 個 description，命中 meeting-action-items
→
③ 載入全文skill_view(name) 讀 SKILL.md + references/
→
④ 執行指定工具照 SOP 調 terminal / API / scripts
→
⑤ 交付產物待辦清單 + 引用 + 後續建議
💡 實用含義：你不需要背指令，只要用自然語言說出任務（「幫我查 arXiv」「幫我做一份 PPT」），模型會自己選 skill。說得越像任務，命中率越高。

6. 黃金組合：4 條實戰 workflow

📝 A. 論文研讀管線

arxiv 找文獻 → grounded-citations 寫摘要（每段掛來源）→ obsidian 存知識庫 → technical-reporting 出 PDF。適合追 SI / 高速文獻。

📊 B. 會議 → 交付管線

teams-meeting-pipeline 轉逐字稿 → meeting-action-items 萃待辦 → notion / google-workspace 同步行事曆 → weekly-review-planning 週覆盤。

🐞 C. 除錯管線

systematic-debugging 定位根因 → spike 小實驗驗證 → test-driven-development 補測試 → requesting-code-review 審查 → github 開 PR（可經 claude-code / codex / opencode 委派）。

🎨 D. 視覺交付管線

architecture-diagram / baoyu-infographic 出圖 → popular-web-designs / claude-design 包成 HTML → hermes-chart-delivery 規範交付（MEDIA / ::preview）。本報告即 D 管線產物。
