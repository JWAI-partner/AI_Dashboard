工具一句話本機狀態
StatiCrypt 靜態 HTML 密碼保護，瀏覽器端 AES 解密、免伺服器（★8.1k，MIT） 已安裝 3.5.4 網站發佈加密靜態網站

用途

把一個 HTML 頁面用密碼加密後直接丟上靜態主機（GitHub Pages / Netlify）；讀者輸密碼在瀏覽器內解密，不需後端。適合發佈本入口網這類研究報告。

本機狀態

已安裝 staticrypt@3.5.4（npm 全域）。2026-10-12 實測在列。

安裝（僅供參考，需你的允許才執行）

npm install -g staticrypt
staticrypt 報告.html -d . --remember 30 --short

來源

github.com/robinmoisson/staticrypt

REA Reverse Engineer Anything：一個 MCP 搞定 binary / App / runtime 逆向，附證據回傳（MIT） 未安裝 逆向工程MCPAgent

用途

Agent 透過 MCP 呼叫 REA，檢查目標程式（native binary、APK、韌體、網站、WASM、EVM bytecode 等）並回傳帶證據的發現；可接 Hopper / Ghidra / IDA 做 native 分析，靜態 JS 分析不需要引擎。

本機狀態

未安裝。npm 套件名 rea-agents。安裝前會先請你允許（含是否一併裝 Hopper 的選項）。

安裝（僅供參考，需你的允許才執行）

npm install -g rea-agents
rea setup   # 註冊到你的 agent（Claude Code / Codex / Cursor / Gemini CLI…）

來源

github.com/morluto/rea · rea.tools
